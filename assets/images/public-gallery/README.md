# TBBA Public Gallery

Place approved public-facing TBBA photos in this folder. The public website discovers supported files automatically and creates the gallery without additional code changes.

Supported formats: JPG, JPEG, PNG, WebP and AVIF.

Use descriptive filenames because the filename becomes the photo caption:

- `team-annual-strategy-meeting.jpg` → category: TBBA Team, caption: Annual Strategy Meeting
- `tender-moe-project-award.jpg` → category: Tender Milestone, caption: MOE Project Award
- `win-government-tender-2026.jpg` → category: Tender Milestone, caption: Government Tender 2026
- `project-northern-region-deployment.jpg` → category: Project Delivery, caption: Northern Region Deployment

Only use images approved for public publication. Avoid exposing confidential tender documents, pricing, personal identification details or client information that is not already public.
