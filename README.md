# 🏢 Management System TBBA (Internal Portal & Mini ERP)

<a name="readme-top"></a>

## 📌 About The Project
An internal company portal and mini ERP system built for **The Bridge Business Alliance (TBBA)**. This platform streamlines internal operations, featuring secure user management, multi-tier staff roles, attendance tracking, and institutional tender preparation tools to boost daily productivity.

---

## 🛠️ Built With
* **Language:** Native PHP, JavaScript
* **Database:** MySQL
* **Styling & UI:** Tailwind CSS / Bootstrap
* **Architecture / Features:** Progressive Web App (PWA) support, Audit Logging

---

## ✨ Key Features
* **Internal Company Portal & Dashboard:** Centralized hub for staff and management to oversee daily company workflows.
* **Attendance & Staff Tracking:** Digital tracking system for employee attendance and activity logs.
* **Tender Board & Management:** Specialized modules for preparing, tracking, and managing government and institutional tenders.
* **Role-Based Access Control (RBAC):** Secure permission levels for Superadmin, Admin, Staff, and general users.
* **Audit & System Health Logs:** Real-time monitoring of system activities, errors, and security audits.
